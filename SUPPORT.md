# Support

## Getting help

For usage questions, troubleshooting, and setup issues:

1. Read README.md, RELEASE.md, and CONTRIBUTING.md first.
2. Search existing issues in the repository.
3. Open a new issue using the available templates if needed.

## What to include in support requests

- Device and iOS version
- Whether issue appears on simulator, device, or both
- Steps to reproduce
- Expected behavior vs actual behavior
- Relevant logs/screenshots (with sensitive data removed)

## Security-related reports

Do not post security vulnerabilities publicly in issues.
Please follow SECURITY.md for coordinated disclosure.

## Response expectations

The project is maintained on a best-effort basis. Response times may vary depending on complexity and maintainer availability.

## Triage quality bar

Support requests with complete reproduction details are prioritized. Requests missing environment data or clear steps may require follow-up before investigation starts.
